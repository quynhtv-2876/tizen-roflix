# T1.1 — Remove RoPhim Source & Puppeteer

**Phase**: 1 — Server Cleanup  
**Status**: `TODO`  
**Depends on**: nothing  
**Spec ref**: `.agents/spec.md` → Section 4 (Out of Scope: RoPhim)

---

## Objective

Remove the RoPhim scraping router (Puppeteer-based) from the server to reduce complexity, RAM usage, and Docker image size. After this task, the server only serves NguonC content.

---

## Context

Current state of `roflix-server/server.js`:
- Lines ~1–120: shared middleware, utilities, NguonC router
- Lines ~123–276: **RoPhim router** (to be deleted)
- Lines ~277–560: HLS proxy, auth middleware, error handler
- `package.json` includes: `puppeteer-core`, `puppeteer-extra`, `puppeteer-extra-plugin-stealth`

---

## Steps

### Step 1: Remove RoPhim route from server.js

Find and delete the following in `roflix-server/server.js`:

**Functions/code to remove:**
- `launchBrowser()` function
- `autoScroll()` function
- `rophimRouter` Express router (entire block)
- `app.use('/api/rophim', rophimRouter)` registration line
- Any `require('puppeteer-core')`, `require('puppeteer-extra')` imports at the top

**Leave intact:**
- `nguoncRouter` and all its routes
- HLS proxy handler (`/api/proxy`)
- Auth middleware (`authenticateKey`)
- `callNguonCApi()` utility function

### Step 2: Update package.json

```json
// REMOVE these from "dependencies":
"puppeteer-core": "^24.24.0",
"puppeteer-extra": "^3.3.6",
"puppeteer-extra-plugin-stealth": "^2.11.2"
```

Run:
```bash
cd roflix-server
npm uninstall puppeteer-core puppeteer-extra puppeteer-extra-plugin-stealth
```

### Step 3: Remove CHROME_PATH from .env.example

```bash
# DELETE this line from .env.example:
CHROME_PATH=/usr/bin/chromium
```

### Step 4: Verify server starts

```bash
cd roflix-server
npm start
# Expected: server listening on port 3000, no Puppeteer-related errors
```
