# T3.1 — Remove Source Selection View (Client)

**Phase**: 3 — Client Refactor  
**Status**: `TODO`  
**Depends on**: Phase 1 complete (T1.1, T1.2, T1.3)  
**Spec ref**: `.agents/spec.md` → Section 4.1 (Grid View launches directly)

---

## Objective

Remove the "source selection" screen from the Tizen TV client (`roflix/index.html`) so the app launches directly into the movie grid. The app will only use the NguonC source (no more RoPhim choice).

---

## Context — Current State

`roflix/index.html` currently has:
- A `<div id="source-selection-view">` with NguonC / RoPhim buttons
- `let currentView = 'sourceSelection'` — the initial view
- `let currentSource = 'nguonc'` — mutable
- Key handlers for LEFT/RIGHT to switch source buttons
- Back button from grid → returns to sourceSelection
- Back button from sourceSelection → exits app

After this task, everything must work without the sourceSelection step.

---

## Steps

### Step 1: Change initial view state

Find and update the JS global state variables:

```javascript
// BEFORE:
let currentView = 'sourceSelection';
let currentSource = 'nguonc';

// AFTER:
let currentView = 'grid';
const currentSource = 'nguonc'; // constant — only NguonC now
```

### Step 2: Remove source-selection-view HTML

Find the `<div id="source-selection-view">` element and **delete it entirely**, including all its children (the two source buttons).

```html
<!-- DELETE THIS ENTIRE BLOCK: -->
<div id="source-selection-view" class="view active">
  ...
</div>
```

### Step 3: Remove source selection CSS

Find and delete CSS rules for:
- `#source-selection-view`
- `.source-btn`
- `.source-btn.focused`
- Any CSS targeting `sourceSelection` views

These are typically in a `<style>` block inside `index.html`.

### Step 4: Update back button handling

Find the `keydown` handler or `handleBackButton()` function:

```javascript
// BEFORE:
else if (currentView === 'grid') {
    switchView('sourceSelection');
}
// ...
else if (currentView === 'sourceSelection') {
    tizen.application.getCurrentApplication().exit();
}

// AFTER:
else if (currentView === 'grid') {
    tizen.application.getCurrentApplication().exit();
}
```

### Step 5: Remove source selection key handling

Find and remove key handlers for LEFT/RIGHT arrows that were navigating between NguonC/RoPhim source buttons when `currentView === 'sourceSelection'`. These blocks look like:

```javascript
// DELETE blocks like:
if (currentView === 'sourceSelection') {
    if (key === KEY_CODES.LEFT) { ... }
    if (key === KEY_CODES.RIGHT) { ... }
    if (key === KEY_CODES.ENTER) { ... }
    return;
}
```

### Step 6: Call initialization directly into grid

The `init()` or `DOMContentLoaded` function currently shows `sourceSelection` first. Change it to initialize the grid directly:

```javascript
// BEFORE:
function initApp() {
    switchView('sourceSelection');
}

// AFTER:
function initApp() {
    switchView('grid');
    fetchMovies(true); // load initial batch
}
```

### Step 7: Update config.xml version

```xml
<!-- BEFORE: -->
<widget ... version="1.0.0">
    <name>RoFlix</name>

<!-- AFTER: -->
<widget ... version="2.0.0">
    <name>RoFlix</name>
```

## Acceptance Criteria

- [ ] App loads directly into movie grid (no source selection screen appears)
- [ ] Movies start loading immediately on app launch
- [ ] Back button from grid exits the app (no crash, no blank screen)
- [ ] `currentSource` is effectively locked to `'nguonc'` (no RoPhim API calls)
- [ ] No JavaScript errors in browser console related to missing elements
- [ ] No dead code references to `rophim` or `sourceSelection` remain in the file
- [ ] config.xml version is `2.0.0`

## Testing

1. Open `roflix/index.html` in a browser (Chrome recommended)
2. Verify the first visible screen is the movie grid (not two buttons)
3. Navigate with arrow keys → should move between movie cards
4. Press BACK / Escape → check console for exit (or `confirm()` in browser)
5. Check browser DevTools console for any errors

## Notes

- The `switchView(viewName)` utility typically handles showing/hiding `.view` elements with `classList.toggle('active')`. Don't change its core logic.
- After removing source selection, search `index.html` for any remaining `'rophim'` or `'sourceSelection'` strings and remove them.
- The client's `fetchApi()` helper builds URLs using `currentSource` — after making it a `const`, verify it still constructs the correct `/api/nguonc/...` paths.
