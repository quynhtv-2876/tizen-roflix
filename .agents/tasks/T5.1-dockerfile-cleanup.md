# T5.1 — Dockerfile Cleanup (Remove Chromium, Add SQLite Volume)

**Phase**: 5 — Docker + Deployment  
**Status**: `TODO`  
**Depends on**: Phase 1 complete (T1.1 — Puppeteer removed from code)  
**Spec ref**: `.agents/spec.md` → Section 5 (Non-Functional: Docker-friendly)

---

## Objective

Update `roflix-server/Dockerfile` to:
1. Remove all Chromium/browser dependencies (no longer needed after removing RoPhim)
2. Add a Docker volume for the SQLite database at `/app/data`
3. Ensure the image is lean and production-ready

---

## Current State

The existing `Dockerfile` installs Chromium and several browser dependencies for Puppeteer. This added ~500MB+ to the image. After removing RoPhim, these are unnecessary.

---

## Steps

### Step 1: Rewrite the Dockerfile

Replace the content of `roflix-server/Dockerfile` with:

```dockerfile
# ─── Stage 1: Dependencies ────────────────────────────────────────────────────
FROM node:22-slim AS deps

WORKDIR /app

COPY package.json package-lock.json* yarn.lock* ./

# Install production dependencies only
RUN npm ci --omit=dev

# ─── Stage 2: Production Image ────────────────────────────────────────────────
FROM node:22-slim AS runner

# Install only the minimal system dependencies for better-sqlite3
RUN apt-get update && apt-get install -y --no-install-recommends \
    ca-certificates \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

# Copy production dependencies from deps stage
COPY --from=deps /app/node_modules ./node_modules

# Copy application files
COPY server.js ./
COPY db.js ./
COPY healthcheck.js ./
COPY .env.example ./.env.example

# Create data directory for SQLite database
RUN mkdir -p /app/data

# Non-root user for security
RUN addgroup --system --gid 1001 nodejs \
    && adduser --system --uid 1001 nodeapp \
    && chown -R nodeapp:nodejs /app

USER nodeapp

# Expose port
EXPOSE 3000

# Health check
HEALTHCHECK --interval=30s --timeout=10s --start-period=10s --retries=3 \
    CMD node healthcheck.js

# Start server
CMD ["node", "server.js"]
```

### Step 2: Add VOLUME declaration for SQLite persistence

Add after the `RUN mkdir -p /app/data` line:

```dockerfile
# Persist SQLite database across container restarts
VOLUME ["/app/data"]
```

### Step 3: Create/Update .dockerignore

Ensure `roflix-server/.dockerignore` contains:

```
node_modules
.git
.gitignore
*.md
data/
.env
```

### Step 4: Test the Docker build

```bash
cd roflix-server
docker build -t roflix-server:latest .

# Check image size (should be < 300MB now vs. ~800MB+ before)
docker images roflix-server

# Run with volume mount
docker run -d \
  --name roflix-server \
  -p 3000:3000 \
  -v $(pwd)/data:/app/data \
  -e API_KEY=ROFLIX_SUPER_SECRET_KEY_123 \
  -e OPHIM_API_URL=https://phim.nguonc.com/api \
  roflix-server:latest

# Test health
sleep 5
curl http://localhost:3000/health

# Cleanup
docker stop roflix-server && docker rm roflix-server
```

## Notes

- `better-sqlite3` is a native module — it may require `python3` and `make` during `npm ci`. If build fails, add to Dockerfile:
  ```dockerfile
  RUN apt-get install -y python3 make g++
  ```
  But try without first — the npm package ships prebuilt binaries for common Node.js versions.
- The `VOLUME` instruction does NOT mount the volume by default — users must use `-v` flag at `docker run` time. Document this in T5.2.
