## Objective

Add two new API endpoints to `roflix-server/server.js` for saving and retrieving per-episode watch positions. These will be called by the client player to support the "Continue Watching" feature.

---

## Endpoints to Implement

### POST /api/nguonc/watch-position

**Save playback position**

Request body (JSON):
```json
{
  "movieSlug": "ten-phim",
  "episodeName": "Tập 1",
  "position": 245
}
```

Response (200):
```json
{ "success": true }
```

Response (400 — missing fields):
```json
{ "message": "Thiếu thông tin: movieSlug, episodeName, position" }
```

---

### GET /api/nguonc/watch-position

**Get saved playback position**

Query params:
- `movieSlug` (required)
- `episodeName` (required)

Response (200):
```json
{ "position": 245 }
```

Response if not found:
```json
{ "position": 0 }
```

---

## Steps

### Step 1: Add POST endpoint to nguoncRouter in server.js

Add after the existing `/watch` endpoint (before the router export/registration):

```javascript
// POST /api/nguonc/watch-position — Save watch position
nguoncRouter.post('/watch-position', express.json(), (req, res) => {
  try {
    const { movieSlug, episodeName, position } = req.body;

    if (!movieSlug || !episodeName || position === undefined) {
      return res.status(400).json({
        message: 'Thiếu thông tin: movieSlug, episodeName, position',
      });
    }

    const pos = parseInt(position, 10);
    if (isNaN(pos) || pos < 0) {
      return res.status(400).json({ message: 'position phải là số nguyên không âm' });
    }

    db.saveWatchPosition(movieSlug, episodeName, pos);
    console.log(`[DB] Saved position ${pos}s for ${movieSlug} — ${episodeName}`);
    res.json({ success: true });
  } catch (error) {
    console.error('[DB] /watch-position POST error:', error.message);
    res.status(500).json({ message: 'Lỗi khi lưu vị trí xem', error: error.message });
  }
});
```

### Step 2: Add GET endpoint to nguoncRouter in server.js

```javascript
// GET /api/nguonc/watch-position — Get watch position
nguoncRouter.get('/watch-position', (req, res) => {
  try {
    const { movieSlug, episodeName } = req.query;

    if (!movieSlug || !episodeName) {
      return res.status(400).json({
        message: 'Thiếu query params: movieSlug, episodeName',
      });
    }

    const position = db.getWatchPosition(movieSlug, episodeName);
    res.json({ position });
  } catch (error) {
    console.error('[DB] /watch-position GET error:', error.message);
    res.status(500).json({ message: 'Lỗi khi lấy vị trí xem', error: error.message });
  }
});
```

### Step 3: Ensure express.json() middleware is available

If `express.json()` is not already applied globally, add it at the top of server.js setup:

```javascript
app.use(express.json());
```

## Acceptance Criteria

- [ ] `POST /api/nguonc/watch-position` with valid body returns `{ "success": true }` (200)
- [ ] `GET /api/nguonc/watch-position?movieSlug=x&episodeName=y` returns saved position
- [ ] After server restart, position is still retrievable (confirmed via SQLite persistence)
- [ ] Second `POST` for same slug+episode **updates** (not duplicates) the position
- [ ] Missing body fields → 400 response
- [ ] Unknown slug → `{ "position": 0 }` (not 404)

## Notes

- Both endpoints are under the **authenticated** `nguoncRouter`, so they require the `X-API-KEY` header.
- `position` is stored in **seconds** (integer). The client should convert before saving.
- The client helper functions for these endpoints will be implemented in **T4.1**.
