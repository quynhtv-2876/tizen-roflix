# T1.3 — Integrate SQLite Cache into NguonC Endpoints

**Phase**: 1 — Server Cleanup  
**Status**: `TODO`  
**Depends on**: T1.2 (db.js must exist)  
**Spec ref**: `.agents/spec.md` → Section 4.1 (Movie Discovery), 4.3 (Movie Detail)

---

## Objective

Update `roflix-server/server.js` to use the SQLite cache (from `db.js`) in the NguonC endpoints:
- `GET /api/nguonc/phimhay` → check cache first, fallback to API, then store in cache
- `GET /api/nguonc/details` → same pattern

---

## Steps

### Step 1: Import db module at top of server.js

At the top of `server.js`, after the existing `require` statements, add:

```javascript
const db = require('./db');
```

### Step 2: Update /api/nguonc/phimhay endpoint

Replace the existing implementation of `nguoncRouter.get('/phimhay', ...)` with:

```javascript
nguoncRouter.get('/phimhay', async (req, res) => {
  try {
    const batch = parseInt(req.query.batch) || 1;

    // 1. Check cache
    const cached = db.getMoviesCache(batch);
    if (cached.length > 0) {
      console.log(`[NGUONC] Cache HIT: ${cached.length} movies for batch ${batch}`);
      return res.json({ movies: cached, batch, hasMore: true, source: 'cache' });
    }

    // 2. Cache miss — fetch from API
    console.log(`[NGUONC] Cache MISS for batch ${batch} — fetching from API`);
    const pagesPerBatch = 3;
    const startPage = (batch - 1) * pagesPerBatch + 1;
    const endPage = batch * pagesPerBatch;

    const promises = [];
    for (let page = startPage; page <= endPage; page++) {
      promises.push(callNguonCApi(`/films/phim-moi-cap-nhat?page=${page}`));
    }
    const results = await Promise.all(promises);

    const allMovies = [];
    for (const data of results) {
      if (data && data.items) {
        const movies = data.items.map(item => ({
          title: item.name,
          link: `/phim/${item.slug}`,
          imageUrl: makeAbsoluteUrl(item.poster_url, OPHIM_DOMAIN),
          slug: item.slug,
        }));
        allMovies.push(...movies);
      }
    }

    // 3. Store in cache
    if (allMovies.length > 0) {
      db.cacheMovies(allMovies, batch);
    }

    res.json({ movies: allMovies, batch, hasMore: allMovies.length >= 30, source: 'api' });
  } catch (error) {
    console.error('[NGUONC] /phimhay error:', error.message);
    res.status(500).json({ message: 'Lỗi khi lấy danh sách phim', error: error.message });
  }
});
```

> **Note**: Adjust the function/variable names (`callNguonCApi`, `makeAbsoluteUrl`, `OPHIM_DOMAIN`) to match the actual names used in `server.js`.

### Step 3: Update /api/nguonc/details endpoint

Replace the existing implementation of `nguoncRouter.get('/details', ...)` with:

```javascript
nguoncRouter.get('/details', async (req, res) => {
  try {
    const { movieSlug } = req.query;
    if (!movieSlug) {
      return res.status(400).json({ message: 'Thiếu movieSlug' });
    }

    // 1. Check cache
    const cached = db.getEpisodeCache(movieSlug);
    if (cached) {
      console.log(`[NGUONC] Episode cache HIT for slug: ${movieSlug}`);
      return res.json({ ...cached, source: 'cache' });
    }

    // 2. Cache miss — fetch from API
    console.log(`[NGUONC] Episode cache MISS for slug: ${movieSlug} — fetching from API`);
    const data = await callNguonCApi(`/film/${movieSlug}`);
    if (!data || !data.movie) {
      return res.status(404).json({ message: 'Không tìm thấy phim' });
    }

    const episodesByServer = (data.episodes || []).map(serverGroup => ({
      server_name: serverGroup.server_name,
      episodes: (serverGroup.items || []).map(ep => ({
        name: ep.name,
        link: makeAbsoluteUrl(ep.embed, OPHIM_DOMAIN),
        direct_link_m3u8: makeAbsoluteUrl(ep.m3u8, OPHIM_DOMAIN),
      })),
    }));

    const movieData = {
      title: data.movie.name,
      origin_title: data.movie.original_name || null,
      description: cheerio.load(data.movie.description || '').text(),
      imageUrl: makeAbsoluteUrl(data.movie.poster_url, OPHIM_DOMAIN),
      episodes: episodesByServer,
    };

    // 3. Store in cache
    db.cacheEpisodes(movieSlug, movieData);

    res.json({ ...movieData, source: 'api' });
  } catch (error) {
    console.error('[NGUONC] /details error:', error.message);
    res.status(500).json({ message: 'Lỗi khi lấy chi tiết phim', error: error.message });
  }
});
```

---

## Acceptance Criteria

- [ ] First call to `GET /api/nguonc/phimhay?batch=1` returns data with `"source": "api"` and logs "Cache MISS"
- [ ] Second call returns data with `"source": "cache"` and logs "Cache HIT"
- [ ] Cache hit response time < 50ms (measure with `curl -w "%{time_total}"`)
- [ ] First call to `GET /api/nguonc/details?movieSlug=<slug>` returns `"source": "api"`
- [ ] Second call to same slug returns `"source": "cache"`
- [ ] Invalid `movieSlug` returns 404
- [ ] Missing `movieSlug` param returns 400

## Notes

- Keep the `source` field in the response — it's useful for debugging but won't break the client.
- Don't cache the `search` endpoint — search results are user-driven and change frequently.
- The `watch-position` endpoints are added in **T2.1** (separate task).
