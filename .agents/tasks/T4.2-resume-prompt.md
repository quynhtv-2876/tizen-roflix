# T4.2 — Resume Prompt (Continue Watching Dialog)

**Status**: `TODO`

**Spec ref**: `.agents/spec.md` → Section 4.3 (Details View — resume prompt), 4.4 (Video Player)

## Objective

When a user selects an episode that was previously watched (has a saved position > 60 seconds), show a dialog asking:
> "Tiếp tục từ 04:05?" → [Tiếp tục] / [Xem từ đầu]

The user navigates the dialog with D-pad and selects with ENTER.

---

## Context

- `playSelectedEpisode()` is called when user presses ENTER on an episode in the details view
- `getWatchPosition(slug, episodeName)` fetches the saved position from the server (returns seconds or 0)
- The video player starts by calling `startVideoPlayback(videoUrl)` or equivalent

### Step 4: Add formatTime() helper

```javascript
/**
 * Format seconds into MM:SS string.
 * @param {number} seconds
 * @returns {string}
 */
function formatTime(seconds) {
  const m = Math.floor(seconds / 60).toString().padStart(2, '0');
  const s = Math.floor(seconds % 60).toString().padStart(2, '0');
  return `${m}:${s}`;
}
```

### Step 5: Rewrite playSelectedEpisode() with resume logic

```javascript
async function playSelectedEpisode() {
  const episode = episodesData[episodeServerIndex]?.episodes[episodeIndex];
  if (!episode) return;

  try {
    // Fetch proxy video URL from server
    const params = new URLSearchParams({
      direct_link_m3u8: episode.direct_link_m3u8,
      episodeLink: episode.link || '',
    });
    const data = await fetchApi(`/nguonc/watch?${params}`);
    const videoUrl = data?.videoUrl;
    if (!videoUrl) throw new Error('Không có link video');

    // Check for saved position
    const savedPosition = await getWatchPosition(
      currentMovieData.slug,
      episode.name
    );

    if (savedPosition > 60) {
      // Show resume dialog
      pendingVideoUrl = videoUrl;
      pendingResumePosition = savedPosition;
      showResumeDialog(savedPosition);
    } else {
      // Play from beginning
      startVideoPlayback(videoUrl, 0);
    }
  } catch (error) {
    console.error('[PLAYER] Failed to get video URL:', error.message);
    // Show error to user (optional toast or alert)
  }
}
```

### Step 6: Add showResumeDialog() and hideResumeDialog()

```javascript
function showResumeDialog(position) {
  const dialog = document.getElementById('resume-dialog');
  const message = document.getElementById('resume-dialog-message');
  message.textContent = `Tiếp tục từ ${formatTime(position)}?`;
  dialogFocusIndex = 0;
  updateDialogFocus();
  dialog.classList.remove('hidden');
  currentView = 'dialog'; // Set view so keydown routes here
}

function hideResumeDialog() {
  document.getElementById('resume-dialog').classList.add('hidden');
  currentView = 'details';
}

function updateDialogFocus() {
  document.getElementById('resume-btn').classList.toggle('focused', dialogFocusIndex === 0);
  document.getElementById('restart-btn').classList.toggle('focused', dialogFocusIndex === 1);
}
```

### Step 7: Add keydown handling for dialog view

In the main `keydown` switch/if handler, add a case for `currentView === 'dialog'`:

```javascript
if (currentView === 'dialog') {
  if (key === KEY_CODES.LEFT || key === KEY_CODES.RIGHT) {
    dialogFocusIndex = dialogFocusIndex === 0 ? 1 : 0;
    updateDialogFocus();
  } else if (key === KEY_CODES.ENTER) {
    hideResumeDialog();
    if (dialogFocusIndex === 0) {
      // Resume
      startVideoPlayback(pendingVideoUrl, pendingResumePosition);
    } else {
      // Restart
      startVideoPlayback(pendingVideoUrl, 0);
    }
  } else if (key === KEY_CODES.BACK) {
    hideResumeDialog();
  }
  return; // Prevent other views from handling this key
}
```

## Acceptance Criteria

- [ ] If saved position > 60s: resume dialog appears before video starts
- [ ] Dialog shows correct time (e.g., "Tiếp tục từ 04:05?")
- [ ] LEFT/RIGHT switches focus between [Tiếp tục] / [Xem từ đầu]
- [ ] ENTER on [Tiếp tục]: video plays from saved position
- [ ] ENTER on [Xem từ đầu]: video plays from 0:00
- [ ] BACK on dialog: dialog closes, returns to details view (no video starts)
- [ ] If saved position ≤ 60s (or 0): no dialog shown, video starts immediately
- [ ] Dialog is visually on top of all other content (z-index 1000)

---

## Testing

1. Play a movie episode for > 2 minutes → press BACK
2. Re-open the same episode → dialog should appear with correct timestamp
3. Select "Tiếp tục" → video starts at saved time
4. Repeat → select "Xem từ đầu" → video starts from beginning
5. Press BACK on dialog → return to details, no video starts

---

## Notes

- The 60-second threshold prevents micro-interruptions (first minute) from triggering the dialog.
- The dialog intentionally uses a simple LEFT/RIGHT navigation (2 buttons only) for simplicity.
- `currentView = 'dialog'` is a new pseudo-view — it doesn't need an HTML `.view` element, just controls key routing.
