## Objective

## Steps

### Step 1: Rewrite .env.example

Replace the contents of `roflix-server/.env.example` with:

```bash
# ─────────────────────────────────────────────────────────────────────────────
# RoFlix Server — Environment Variables
# ─────────────────────────────────────────────────────────────────────────────
# Copy this file: cp .env.example .env
# Edit the values below for your environment.
# ─────────────────────────────────────────────────────────────────────────────

# ─── Server ───────────────────────────────────────────────────────────────────

# Port the Express server listens on
PORT=3000

# ─── Security ─────────────────────────────────────────────────────────────────

# API key that the Tizen TV client must send in the X-API-KEY header.
# Change this to a strong random string.
# To generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
API_KEY=ROFLIX_SUPER_SECRET_KEY_123

# ─── NguonC API ───────────────────────────────────────────────────────────────

# Base URL for the NguonC (OPhim) movie API
OPHIM_API_URL=https://phim.nguonc.com/api

# ─── SQLite (optional override) ───────────────────────────────────────────────

# Path where the SQLite database file is stored.
# Default: <project_root>/data/roflix.db
# Override only if you need a custom path (e.g., Docker volume mount).
# DB_PATH=/app/data/roflix.db
```

### Step 2: Update .gitignore for data directory

Ensure `roflix-server/.gitignore` contains:

```
node_modules/
.env
data/
*.db
```

### Step 3: Add a quick-start comment block to server.js

At the very top of `roflix-server/server.js`, add (or update) the existing header comment:

```javascript
/**
 * RoFlix Server — Node.js/Express backend
 *
 * Quick start:
 *   cp .env.example .env && npm install && npm start
 *
 * Docker:
 *   docker build -t roflix-server .
 *   docker run -p 3000:3000 -v $(pwd)/data:/app/data --env-file .env roflix-server
 *
 * Endpoints:
 *   GET  /api/nguonc/phimhay        - Movie list (batched, cached)
 *   GET  /api/nguonc/search         - Movie search
 *   GET  /api/nguonc/details        - Movie details + episodes (cached)
 *   GET  /api/nguonc/watch          - Get proxy video URL
 *   POST /api/nguonc/watch-position - Save watch position
 *   GET  /api/nguonc/watch-position - Get watch position
 *   GET  /api/proxy                 - HLS video proxy (no auth required)
 *   GET  /health                    - Health check
 *
 * Auth: All /api/nguonc/* routes require X-API-KEY header matching API_KEY env var.
 */
```

## Notes

- The `API_KEY` in `.env.example` is intentionally left as the default test value. The README (if it exists) should warn users to change it.
