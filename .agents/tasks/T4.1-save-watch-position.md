# T4.1 — Auto-Save Watch Position (Client)

**Phase**: 4 — Continue Watching  
**Status**: `TODO`  
**Depends on**: T2.1 (watch-position API), T3.3 (details view)  
**Spec ref**: `.agents/spec.md` → Section 4.4 (Video Player)

---

## Objective

Add client-side logic in `roflix/index.html` to automatically save the current video playback position every 10 seconds while the user is watching. This persists progress so the user can resume later.

---

## Context

- The player view has a `<video>` element with id `video-player` (native) and `hls-player` (HLS.js)
- The active player is referenced by `activePlayer`
- Current movie data is accessible via `currentMovieData` (should have a `slug` field)
- Current episode name is accessible via `episodesData[episodeServerIndex].episodes[episodeIndex].name`

---

## Steps

### Step 1: Add client API helper for saving position

Inside the script section of `index.html`, add two helper functions:

```javascript
/**
 * Save current playback position to the server.
 * @param {string} movieSlug
 * @param {string} episodeName
 * @param {number} positionSeconds
 */
async function saveWatchPosition(movieSlug, episodeName, positionSeconds) {
  try {
    await fetch(`${SERVER_URL}/api/nguonc/watch-position`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-API-KEY': API_KEY,
      },
      body: JSON.stringify({
        movieSlug,
        episodeName,
        position: Math.floor(positionSeconds),
      }),
    });
  } catch (error) {
    console.warn('[PLAYER] Failed to save watch position:', error.message);
    // Non-critical: fail silently
  }
}

/**
 * Get saved playback position from the server.
 * @param {string} movieSlug
 * @param {string} episodeName
 * @returns {Promise<number>} - seconds, or 0 if not found
 */
async function getWatchPosition(movieSlug, episodeName) {
  try {
    const params = new URLSearchParams({ movieSlug, episodeName });
    const data = await fetchApi(`/nguonc/watch-position?${params}`);
    return data?.position || 0;
  } catch (error) {
    console.warn('[PLAYER] Failed to get watch position:', error.message);
    return 0;
  }
}
```

### Step 2: Add position save interval

Declare a global variable for the interval:

```javascript
let watchPositionInterval = null;
```

In the function that starts video playback (likely `playSelectedEpisode()` or `startVideo()`), add the interval after the player starts:

```javascript
// Auto-save position every 10 seconds
if (watchPositionInterval) clearInterval(watchPositionInterval);

watchPositionInterval = setInterval(() => {
  if (activePlayer && !activePlayer.paused && activePlayer.currentTime > 0) {
    const currentEpisodeName = episodesData[episodeServerIndex]?.episodes[episodeIndex]?.name;
    if (currentMovieData?.slug && currentEpisodeName) {
      saveWatchPosition(
        currentMovieData.slug,
        currentEpisodeName,
        activePlayer.currentTime
      );
    }
  }
}, 10000); // every 10 seconds
```

### Step 3: Clear interval when leaving player

When the user presses BACK from the player view (returning to details), clear the interval and **save the final position**:

```javascript
// In the BACK handler for player view:
case KEY_CODES.BACK:
  // Save final position before leaving
  if (activePlayer && activePlayer.currentTime > 0) {
    const currentEpisodeName = episodesData[episodeServerIndex]?.episodes[episodeIndex]?.name;
    if (currentMovieData?.slug && currentEpisodeName) {
      saveWatchPosition(
        currentMovieData.slug,
        currentEpisodeName,
        activePlayer.currentTime
      );
    }
  }

  // Stop interval
  if (watchPositionInterval) {
    clearInterval(watchPositionInterval);
    watchPositionInterval = null;
  }

  // Stop video and return to details
  activePlayer.pause();
  activePlayer.src = '';
  if (hlsInstance) {
    hlsInstance.destroy();
    hlsInstance = null;
  }
  switchView('details');
  break;
```

### Step 4: Ensure currentMovieData.slug is set when loading details

When `fetchMovieDetails(slug)` is called, store the slug on `currentMovieData`:

```javascript
async function fetchMovieDetails(slug) {
  const data = await fetchApi(`/nguonc/details`, { movieSlug: slug });
  currentMovieData = { ...data, slug }; // ensure slug is always on the object
  episodesData = data.episodes || [];
  renderDetails(currentMovieData);
  switchView('details');
}
```

## Acceptance Criteria

- [ ] While in player view, a request to `POST /api/nguonc/watch-position` is made every 10 seconds
- [ ] The saved position matches `Math.floor(activePlayer.currentTime)`
- [ ] On BACK from player, one final save is made before leaving the view
- [ ] Interval is cleared when leaving player (no memory leak, no dangling requests)
- [ ] If the server is unreachable, the save fails silently (no UI disruption)
- [ ] `currentMovieData.slug` is always available when entering the player

---

## Testing

1. Open app in browser, navigate to a movie → episode → play
2. Open DevTools → Network tab → filter by `watch-position`
3. Wait 10 seconds → verify POST request is made with `{ movieSlug, episodeName, position }`
4. Press BACK → verify one final POST is made
5. Verify no further requests are made after returning to details view

---

## Notes

- **10 seconds** is the save interval. This is a balance between data freshness and server load.
- The save is **fire-and-forget** — no UI feedback is needed. Errors should only be logged to console.
- If `activePlayer.paused` is true (video is paused), we still save the position in case the user closes the app.
- The HLS.js player and native player both expose `currentTime` the same way.
