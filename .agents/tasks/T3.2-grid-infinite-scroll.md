## Objective

Polish the movie grid's infinite scroll behavior in `roflix/index.html`:
- Show a loading spinner while fetching
- Prevent duplicate batches from being loaded
- Handle the "end of content" state (no more movies)
- Smooth UX when navigating near the bottom of the grid

---

## Current State

The existing code already has basic batch loading:
- `loadedBatches` counter
- `isLoadingMore` flag
- `fetchMovies(isInitial)` function
- Trigger logic when `gridIndex >= lastItemIndex - (itemsPerRow * 2)`

But polish is missing: no visible spinner, no proper "end of list" message, and edge cases with rapid D-pad presses.

---

### Step 3: Add "no more movies" state tracking

Add a global state variable:

```javascript
let hasMoreMovies = true; // set to false when API returns hasMore: false
```

### Step 4: Update loadMoreMovies() function

Rewrite (or patch) the `loadMoreMovies()` function:

```javascript
async function loadMoreMovies() {
  if (isLoadingMore || !hasMoreMovies) return;

  isLoadingMore = true;
  const spinner = document.getElementById('grid-loading-spinner');
  if (spinner) spinner.classList.remove('hidden');

  try {
    loadedBatches++;
    const data = await fetchApi('/nguonc/phimhay', { batch: loadedBatches });

    if (data && data.movies && data.movies.length > 0) {
      movies = [...movies, ...data.movies];
      hasMoreMovies = data.hasMore !== false;
      renderMovieGrid();
      console.log(`[GRID] Loaded batch ${loadedBatches}: +${data.movies.length} movies (total: ${movies.length})`);
    } else {
      hasMoreMovies = false;
      console.log('[GRID] No more movies to load');
    }
  } catch (error) {
    console.error('[GRID] Failed to load more movies:', error);
    loadedBatches--; // revert counter on failure
  } finally {
    isLoadingMore = false;
    if (spinner) spinner.classList.add('hidden');
  }
}
```

### Step 5: Reset state on grid init

In `fetchMovies(isInitial = true)`:

```javascript
async function fetchMovies(isInitial = true) {
  if (isInitial) {
    movies = [];
    loadedBatches = 1;
    hasMoreMovies = true;
    gridIndex = 0;
  }
  // ... existing fetch logic
}
```

### Step 6: Ensure trigger logic has debounce

In the D-pad DOWN handler for grid view, add a check before triggering load:

```javascript
// Trigger load more when near the bottom
const triggerThreshold = itemsPerRow * 2; // 2 rows before the end
if (gridIndex >= movies.length - triggerThreshold && hasMoreMovies && !isLoadingMore) {
  loadMoreMovies();
}
```

---

## Acceptance Criteria

- [ ] Spinner appears at the bottom of the grid while loading more movies
- [ ] Spinner disappears when loading completes (success or error)
- [ ] `loadMoreMovies()` is not called again while already loading (`isLoadingMore` guard)
- [ ] When `hasMore: false` from server, no more API calls are triggered
- [ ] Navigating near the bottom of grid (within 2 rows of end) triggers batch load
- [ ] On load failure, `loadedBatches` is reverted so next attempt retries the same batch
- [ ] No visual flicker when appending new movies to the grid
